# 🏆 PUBG نۇپۇز (Popularity) ئەۋەتىش ۋە تېلېگرامما بوتى ئارقىلىق دەلىللەش سىستېمىسى

بۇ تۈر خېرىدارلارنىڭ PUBG ئويۇن كىملىكى (UID)، نۇپۇز سانى ۋە ئىسپات سۈرىتىنى تاپشۇرۇشى، سۈرەتنى تور كۆرگۈچ ئىچىدە ئاپتوماتىك سىقىپ Supabase Storage غا ساقلىشى، ھەمدە تېلېگرامما بوتى ئارقىلىق باشقۇرغۇچىغا دەلىللەش كۇنۇپكىسى (Inline Buttons) بار ئۇچۇر ئەۋەتىپ، بىرلا چەككەندە ساندان ۋە كۆرۈنمە يۈزنى يېڭىلايدىغان پۈتۈن سەپلىمىلىك قولايلىق سىستېمىدۇر.

---

## 📁 تۈر ھۆججەت قۇرۇلمىسى (Project Structure)

```text
pubg/
├── index.html       # خېرىدار نۇپۇز تاپشۇرۇش بېتى (UI كۆچمە تېلېفونغا ماسلاشقان قارا ئويۇن ئۇسلۇبى)
├── admin.html       # باشقۇرغۇچى كۆرۈنمە يۈزى (PIN بىلەن كىرىش، كۆرۈش، سۈزۈش، تەستىقلاش)
├── app.js           # ئالدى تەرەپ مەنتىقىسى (سۈرەتنى 500KB غا سىقىش، Supabase غا يۈكلەش، تېلېگراممىغا ئۇقتۇرۇش)
├── config.js        # بىر تۇتاش تەڭشەك ھۆججىتى (Supabase URL, Keys, Telegram Token, Chat ID)
├── bot.py           # تېلېگرامما بوت پايتۇن كودى (Inline Buttons تەستىقلاش/رەت قىلىش)
├── schema.sql       # Supabase جەدۋەل ۋە Storage بەلگىلىمىلىرى (SQL)
├── requirements.txt # پايتۇن كېرەكلىك بوغچىلىرى
└── README.md        # تولۇق ئىشلىتىش ۋە تەڭشەش قوللانمىسى
```

---

## ⚡ تېز قوزغىتىش ۋە سەپلەش قەدەملىرى

### 1-قەدەم: Supabase تەڭشەش
1. [Supabase.com](https://supabase.com) غا كىرىپ يېڭى ھەقسىز تۈر (Project) قۇرۇڭ.
2. سول تەرەپتىكى **SQL Editor** تىزىملىكىگە كىرىپ، مۇشۇ تۈردىكى `schema.sql` كودىنى چاپلاڭ ۋە **Run** كۇنۇپكىسىنى بېسىڭ.
   - بۇ ئاپتوماتىك ھالدا `popularity_submissions` جەدۋىلىنى ۋە `screenshots` ناملىق سۈرەت ئامبىرىنى (Storage Bucket) رۇخسەتلىرى بىلەن قۇرىدۇ.
3. **Project Settings -> API** بۆلىكىدىن:
   - `Project URL`
   - `anon public key`
   لارنى كۆچۈرۈۋېلىڭ.

---

### 2-قەدەم: Telegram Bot تەڭشەش
1. تېلېگراممىدا [@BotFather](https://t.me/BotFather) غا كىرىپ `/newbot` بۇيرۇقى بىلەن يېڭى بوت قۇرۇپ **API Token** نى ئېلىڭ.
2. بوتقا تېلېگراممىدا كىرىپ `/start` نى بېسىپ قوزغىتىڭ.
3. ئۆزىڭىزنىڭ ياكى گۇرۇپپىڭىزنىڭ **Chat ID** سىنى تېپىش ئۈچۈن [@userinfobot](https://t.me/userinfobot) قا كىرىپ `/start` نى بېسىڭ.

---

### 3-قەدەم: `config.js` ھۆججىتىنى تولدۇرۇش
`config.js` نى ئېچىپ، يۇقىرىدىكى ئۇچۇرلارنى ئورنىغا چاپلاڭ:

```javascript
const CONFIG = {
  SUPABASE_URL: "https://your-project.supabase.co",
  SUPABASE_ANON_KEY: "your-anon-key",
  STORAGE_BUCKET: "screenshots",
  TELEGRAM_BOT_TOKEN: "123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ",
  TELEGRAM_CHAT_ID: "987654321",
  ADMIN_PIN: "8888" // باشقۇرغۇچى كىرىش مەخپىي نومۇرى
};
```

---

### 4-قەدەم: تېلېگرامما بوتنى قوزغىتىش (`bot.py`)

كومپيۇتېر ياكى تېلېفوندا (Termux / VPS):

```bash
# كېرەكلىك كۈتۈپخانىلارنى قاچىلاش
pip install -r requirements.txt

# بوتنى يۈرگۈزۈش
python bot.py
```

> 💡 **ئەسكەرتىش:** `bot.py` ھۆججىتى `config.js` دىكى ئاچقۇچلارنى ئاپتوماتىك ئوقۇپ قوزغىلىدۇ.

## 📱 تېلېفوندا ۋە GitHub Pages دا ئىشلىتىش

### GitHub Pages ئارقىلىق ھەقسىز تورغا چىقىرىش:
1. بۇ تۈردىكى بارلىق ھۆججەتلەرنى يېڭى بىر GitHub ئامبىرىغا (Repository) يۈكلەڭ.
2. GitHub دا **Settings -> Pages** قىسمىغا كىرىڭ.
3. **Branch** نى `main` قىلىپ **Save** نى بېسىڭ.
4. بىر نەچچە سېكۇنتتىن كېيىن ئاممىۋى تور ئۇلىنىشى ھاسىل بولىدۇ (مەسىلەن: `https://username.github.io/pubg/`).
5. تېلېفون ياكى كومپيۇتېردىن خالىغان جايدىن بېكەتكە كىرىپ، كۆچمە كۆرۈنمە يۈزنى بىۋاسىتە ئىشلەتكىلى بولىدۇ!

- **سۈرەت سىقىش:** تېلېفوندىن نەچچە مېگابايتلىق رەسىم تاللىسىمۇ، ئالدى بىلەن كۆرگۈچ ئىچىدە سىپتا كىچىكلىتىلىپ (~500KB)، تېز سۈرئەتتە يۈكلىنىدۇ.
- **تېلېگرامما تېز تەستىق:** باشقۇرغۇچى تور بېكەتكە كىرمەيمۇ، تېلېگراممىدا چىققان ئۇچۇرنىڭ ئاستىدىكى «✅ تەستىقلاش» ياكى «❌ رەت قىلىش» كۇنۇپكىسىنى بېسىپلا سانداننى يېڭىلىيالايدۇ.
- **قايتا بېسىشنىڭ ئالدىنى ئېلىش:** بىر قېتىم كۇنۇپكا بېسىلغان ھامان، كۇنۇپكىلار يوقىلىپ مەشغۇلات قىلغۇچىنىڭ ئىسمى ۋە ۋاقتى يېزىلىپ تەستىق ساقلىنىدۇ.
- **باشقۇرغۇچى كۆرۈنمە يۈزى (`admin.html`):** مەخپىي PIN بىلەن كىرىپ، كەلگەن نۇپۇزلارنى كۆرۈش، چوڭايتىپ سۈرەت تەكشۈرۈش ۋە ھالەت سۈزۈش ئىقتىدارى تەمىنلەنگەن.
